analog

A local-first film grain editor: a Rust library, a CLI and a desktop GUI that add film-like grain, halation, print simulation and film color shifts to an already-developed photo. It is a clean-room reimplementation inspired by thegrain.io; the reverse-engineering study that informs the design lives in research.md.

Processing is entirely local: images are never uploaded.

Status

The four effect blocks (Film Color Shift, Grain, Halation, Print Simulation) run on the GPU and are exposed through a library, a CLI and an iced desktop GUI. Images are 8- or 16-bit; focus-based grain uses a neural depth model; recipes import and export as .thegrain XMP. PSD files can be imported (PSD/PSB export and oracle tuning are planned). See doc/roadmap.md.

Layout

crates/
  analog-core/   library: recipe/params data model, image I/O, wgpu engine, WGSL shaders
  analog-cli/    command line tool
  analog-gui/    desktop GUI (iced)

Build and use

Requires a stable Rust toolchain (edition 2024, rustc >= 1.93) and a GPU with Vulkan, Metal or DirectX 12.

cargo build --workspace
cargo test --workspace

# inspect an image
cargo run -p analog-cli -- info photo.jpg
# render with effects
cargo run -p analog-cli -- render in.jpg out.png --film kodak_portra_400 --grain 60 --halation 50
# check the GPU
cargo run -p analog-cli -- gpu-info
# launch the editor
cargo run -p analog-gui

In the editor, hold the Hold to compare (B) button (or the B / \ key) to see the original photo without effects while pressed. Scroll over the photo to zoom in and out around the cursor, drag with the left mouse button to pan while zoomed in, and use the Fit button or a double-click to reset the view.
