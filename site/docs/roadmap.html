Roadmap

Milestones are ordered so that each one produces something testable. Status: [x] done, [~] in progress, [ ] planned.

P0 Setup [x]

  • Git repository, .gitignore.
  • Cargo workspace with analog-core, analog-cli, analog-gui.
  • Documentation skeleton.
  • cargo fmt / clippy / test green.

P1 Data model and image I/O [x]

  • Recipe and the four parameter blocks with documented ranges and defaults.
  • 8-bit RGBA image type; JPEG/PNG/TIFF decode and encode.
  • CLI info and render (pass-through; refuses non-neutral recipes).

P2 GPU skeleton [x]

  • wgpu instance/device with high-performance adapter selection; Error::NoAdapter lets tests skip when no GPU is present.
  • ImageComputePass scaffold: upload RGBA8, dispatch a WGSL entry point with a uniform parameter block, read back.
  • shaders/grayscale.wgsl plumbing pass, verified against a CPU reference.
  • CLI gpu-info command.

P3 Grain [x]

A three-stage pipeline: scatter (deterministic integer-hash value noise with chromatic offsets, fine grain, dissolution clumping, dust specks and scratches), blur (separable box, horizontal then vertical) and apply (adaptive luminance zones, depth-based focus control, mild blur compensation).

  • Deterministic: a given grain_seed reproduces grain exactly.
  • Three grain types, grain size, softness (a real blur), adaptive luminance zones, chromatic grain, fine grain and dissolution.
  • Tests: identity at zero intensity, determinism, seed sensitivity, softness sensitivity, depth focus and alpha preservation.

Remaining: golden-image tests against reference exports (P8).

P4 Halation [x]

  • Bright extraction with a soft knee.
  • Box downsample chain (4 levels) and tent upsample with additive accumulation.
  • Composite: 70 percent additive / 30 percent screen, yellow-to-red tint, highlight protection and a dither to break banding.
  • Tests: determinism, brightening near a hotspot, identity at zero intensity.

Approximations, documented in doc/architecture.md: a regular 1/2 mip chain up to 1/64 rather than the reference’s 1/2, 1/32, 1/128; halation_radius selects how many levels contribute, which controls the bloom spread; depth-aware background handling uses the depth model when present.

P5 Print Simulation [x]

  • Per-paper shadow floor, S-curve and highlight shoulder (matte 0.45/0.72, neutral 0.55/0.78, glossy 0.65/0.84) plus a warm-to-cool paper tint.
  • print_sim_paper_intensity scales the paper character; print_simulation blends the whole effect; print_sim_highlight_rolloff pulls the shoulder in.
  • Tests: matte raises blacks, glossy keeps them dark, identity at zero, determinism.

Approximation: the reference uses Catmull-Rom splines and a cubic-Hermite shoulder; ours uses a smoothstep shoulder.

P6 Film Color Shift [x]

  • A clean-room parametric model per stock: lift/gain/gamma, saturation, shadow/highlight tint (approximating the C-41 orange mask), and for black-and-white stocks a channel mixer plus paper tone.
  • 19 stocks (neutral, 13 colour, 5 black-and-white) with our own profile values.
  • film_stock_intensity blends the look; a neutral stock is an identity.

Deferred: the reference’s content-aware hue-cluster narrowing and its baked 33-cubed LUTs. Our profiles are hand-authored approximations, not derived from any third-party profile.

P7 GUI [x]

  • iced single-window app: open and export buttons, grouped controls for Grain, Halation, Print Simulation and Film Color Shift, paper and stock pickers, grain-type radios and a reseed button.
  • Every parameter in the recipe is reachable: grain Color, Color Shift, Grain Fusion, Fine Grain and the Highlights/Mids/Shadows luminance zones; halation Threshold, Color, Color Shift, Color Tone, Background Focus, Background Gain and Light Spill; print Paper Intensity, Highlight Rolloff and Paper Tint (signed). Less-common controls sit behind a per-section “Advanced” checkbox.
  • Live preview renders a downscaled proxy (longest side 900 px) on the GPU and displays it; export renders the original at full resolution.
  • Hold-to-compare control (button or B / \ key) shows the un-effected original while held.
  • Colour-related sliders (grain Color and Color Shift, halation Color, Color Tone and Color Shift, print Paper Tint) show a gradient swatch above the track to indicate the ramp. The swatch is a guide, not a literal preview: the halation swatches are derived from the engine’s tint_rgb, but the result still depends on the image and the other parameters.
  • The preview is a canvas: scroll over the photo to zoom in and out anchored at the cursor, drag with the left button to pan while zoomed, and use the “Fit” button or double-click to reset. Zoom is clamped to fit..8x and the pan is clamped so the photo never leaves a gap.
  • Verified to launch on X11 (Vulkan).

Depth-based Focus Control [x]

  • Depth Anything V2 Small (onnx-community/depth-anything-v2-small, Apache-2.0) via ONNX Runtime, int8-quantised (~27 MB), downloaded on demand to the user cache.
  • grain.depth_of_field_intensity makes in-focus areas finer and defocused areas softer and larger.
  • halation.halation_background_focus / halation_background_gain suppress the glow on the in-focus subject and boost it in the defocused background.
  • CLI --focus; GUI “Focus Control” slider with lazy model loading.

Approximation: the image is squashed to the model’s 518x518 input rather than aspect-preserving, then the depth map is resampled back.

16-bit pipeline [x]

  • Image carries a PixelFormat (Rgba8 or Rgba16); decode preserves 16-bit PNG/TIFF and encode writes 16-bit when the target format supports it (JPEG falls back to 8-bit).
  • GPU buffers are packed as one u32 per pixel (8-bit) or two (16-bit, R|G and B|A). Passes that touch the image compile for both layouts; auxiliary buffers (grain field, bloom, depth) stay 8-bit.
  • The renderer preserves the input depth end to end: 8-bit in gives 8-bit out, 16-bit in gives 16-bit out.

PSD import [x]

  • PSD files are decoded to their flattened (composited) 8-bit RGBA image via the psd crate. Some PSD variants make the crate panic; that is caught and surfaced as an error rather than crashing.
  • PSB is not supported by the reader, and PSD/PSB export is not implemented (the CLI reports this clearly). Use PNG or TIFF for output.

.thegrain recipes [x]

  • Import and export of the .thegrain XMP format (tgrain: namespace, schema version 1), plus bare .xmp. Attribute names mirror the internal schema.
  • Import is lenient (missing attributes fall back to defaults) and accepts coated/uncoated paper aliases; names are truncated to 100 characters and presets over 64 KB are rejected, matching the reference client.
  • CLI: analog preset in.json out.thegrain converts between JSON and XMP; render --recipe accepts either.

Interactive performance [x]

  • GPU-resident pipeline: passes hand GpuImage buffers to each other with a single readback at the end (was: a readback and a CPU repack per pass).
  • Lazy, per-format pipeline compilation, so startup does not compile unused pipelines.
  • GUI debounce (60 ms) plus a 320 px coarse proxy while dragging.
  • Details and measurements in performance.md and decisions/0005-gpu-resident-pipeline.md.

Deferred (documented to fix later)

Known gaps accepted for now, each with its home milestone:

  • Halation fidelity (P4): a regular 1/2 mip chain up to 1/64 replaces the reference’s 1/2, 1/32, 1/128; halation_radius selects the number of levels rather than an exact kernel radius.
  • Depth-dependent controls: implemented; see the Depth-based Focus Control milestone. The model input is squashed to 518x518 rather than aspect-preserving.
  • Film fidelity (P6): our film profiles are hand-authored approximations; the reference’s content-aware hue-cluster narrowing and baked LUTs are not reproduced.
  • Oracle tuning (P8): no comparison harness yet; see above.
  • Buffer pooling: each GPU pass still allocates a fresh output buffer.
