# Static project site

A small, dependency-light static site for `analog`:

- **Home** (`index.html`): the repository `README.md`, rendered with Pandoc.
- **Downloads** (`downloads.html`): binaries from the **latest GitHub release**,
  fetched from the Releases API at build time (no hardcoded versions).
- **Documentation** (`docs/`): the mdBook built from `../docs/`.

Everything is generated by `build.sh`; the site is plain static files and needs
no backend.

## Build

Requirements: `pandoc`, `mdbook`, `curl`, `python3`.

```sh
bash site/build.sh
```

The output lands in `site/` (the generated `index.html`, `downloads.html` and
`docs/` are committed, matching the project's deployment strategy). Preview it:

```sh
python3 -m http.server -d site
```

The repository URL defaults to `https://github.com/apanoush/analog`. Override it
with `REPO_URL`, and set `GITHUB_TOKEN` to lift the Releases API rate limit:

```sh
REPO_URL=https://github.com/you/analog GITHUB_TOKEN=... bash site/build.sh
```

If the latest release cannot be fetched the build fails on purpose: it never
falls back to an outdated version.

## Files

| Path | Purpose |
| --- | --- |
| `build.sh` | Reproducible build: downloads, landing page, mdBook. |
| `template.html` | Pandoc template for the landing page. |
| `rewrite-links.lua` | Pandoc filter that rewrites README `docs/*.md` links to the built HTML. |
| `gen_downloads.py` | Renders the downloads page from the release JSON. |
| `downloads.template.html` | Template for the downloads page. |
| `assets/style.css` | Shared styles (light/dark, responsive). |
| `docs/`, `index.html`, `downloads.html` | Generated output. |

## Deploy

`.github/workflows/pages.yml` builds the site and deploys `site/` to GitHub
Pages on every push to `public` (and on manual dispatch). Enable it once in the
repository settings: **Pages -> Build and deployment -> Source -> GitHub
Actions**.
